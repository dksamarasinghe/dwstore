== Description ==

Koko WooCommerce Plugin allows you to accept payments on your WooCommerce store via KOKO accounts and allows installment-based payments.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/paykoko` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to WooCommerce > Settings > Payments and enable "Koko: Buy Now Pay Later".
4. Configure your Koko settings, including merchant ID and API keys.

== Frequently Asked Questions ==

= Do I need a Koko account to use this plugin? =

Yes, you need to have a Koko account and obtain your merchant ID and API keys to use this plugin.

= Is there a test mode available? =

Yes, the plugin has a sandbox mode that you can enable in the settings for testing purposes.
