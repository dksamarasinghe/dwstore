== Description ==

<h3>Payzy Payment Gateway for WooCommerce</h3> makes your website ready to use payzy payment gateway to accept credit/debit cards with installments on your woocommerce store in safe way.



Payzy is most widely used payment gateway to process payments with buy now pay later with interest free installments.

= Features =
Few features of this plugin:

1. Easy to install and configure
2. Safe way to process credit cards and debit cards on WooCommerce using payzy
3. Payment is processed on secured servers of Payzy.lk

Easy steps to install the plugin:

1. Upload `payzy` folder/directory to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to WooCommerce => Settings
4. On the "Settings" page, select "Payment Gateways" tab.
5. Under "Payment Gateways" you will find all the available gateways, select "Payzy" option
6. On this page you wil find option to configure the plugin for use with WooCommerce
7. Enter the API details
